# FTTH Optical Network

Mô phỏng hệ thống mạng truy nhập quang FTTH bằng OptiSystem.

- Tốc độ truyền: 1 Gbps
- Khoảng cách tối đa: 20 km
- Số lượng thuê bao: 32
- Bộ chia quang: 1×4 và 1×8
- Khuếch đại quang: EDFA
- Đánh giá hiệu năng bằng BER
